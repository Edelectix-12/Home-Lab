# Home-Lab
This environment will be my first Home Lab

The goal of this project is to build practical experience with Linux server administration, virtualization, networking, Docker, monitoring, security and self-hosted applications.

I will gradually build a personal server environment and document every step.

-----
Lab Environment
-

Virtual Machine

- Linux Server (Main Server)

Operating System:

- Ubuntu Server LTS

Purpose:

- Docker Host
- Reverse Proxy
- Monitoring
- Self-Hosted Applications

Project Roadmap
-

Phase 1 - Linux Iniciations

- Install Ubuntu Server
- Configure networking
- User and permissions management
- Basic firewall configuration
- System updates and maintenance

Phase 2 - Docker

- Install Docker
- Install Docker Compose
- Create custom Docker networks
- Manage volumes and persistent storage

Phase 3 - Self-Hosted Applications

Applications will be selected and deployed from the Awesome Self-Hosted project.

Potential services include:

- Adminer for MySQL / MariaDB as Database Management
- Pi-hole Home as DNS
- Uptime Kuma as Monitoring & Status Pages
- Dashy as Personal Dashboard
- Jellyfin as Software Media System

Phase 4 - Monitoring

- Grafana
- Prometheus
- System monitoring
- Service monitoring

Each application will have its own documentation page describing:

- Installation process
- Configuration
- Issues encountered
- Lessons learned

Current Status
-

Phase 1, 2 completed, the docker is running with no errors, everything can be checked in the doc.md file


Next Objective:
-

Continue with the Phase 3 to improve the docker applications.
